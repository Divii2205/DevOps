  SCOPE SUMMARY
  nodePort      node / host network   outside the cluster     NodePort + LoadBalancer only
  port          Service virtual IP    inside the cluster      every Service type
  targetPort    pod IP                inside the cluster      resolves named ports too
  containerPort pod's own netns       informational only      Pod spec, not Service spec
